# Typography

## Philosophy

Typography should feel editorial and luxurious, like a fashion magazine.

The contrast between a serif display font and a modern sans-serif body font creates the feeling of:

* Fashion Editorial
* Luxury Retail
* Modern Product Experience

---

## Font Stack

### Display Font

Cormorant Garamond

Used for:

* Hero Headlines
* Collection Titles
* Moodboard Titles
* Editorial Sections
* Major Page Headings

Examples:

* What are we shopping for today?
* Women's Leadership Conference
* Modern South Indian Wedding
* Summer in Tuscany

---

### Body Font

Inter

Used for:

* Navigation
* Product Information
* AI Stylist Notes
* Form Inputs
* Descriptions
* UI Components

Examples:

* Product details
* AI recommendations
* Friend comments
* Search and filters

## Rules

1. Never use more than two font families.

2. Use Cormorant Garamond only for editorial moments.

3. Use Inter for everything interactive.

4. Avoid excessive font weights.

5. Prefer whitespace and hierarchy over bold text.

6. Every screen should feel closer to a fashion lookbook than a SaaS dashboard.

# Motion

Fast: 150ms

Standard: 250ms

Slow: 400ms


Motion should feel elegant.

Never bouncy.

Never playful.

More fashion show.
Less gaming UI.
